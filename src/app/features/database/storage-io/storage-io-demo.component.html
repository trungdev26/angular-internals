Kết luận: Logical read mô tả nhu cầu đọc page của query; Physical read chỉ xuất hiện khi Buffer Pool không có page. Execution plan giống nhau không bảo đảm latency giống nhau nếu trạng thái cache khác nhau.

Kết luận: Buffer Pool hiệu quả khi working set đang hoạt động nằm vừa RAM. Sequential scan hoặc report lớn có thể thay các hot page, làm workload khác chịu cache miss dù không đổi query.

Kết luận: WAL bảo vệ durability của transaction trước khi data page được flush. Dirty Page là trạng thái bình thường; rủi ro xuất hiện khi WAL chưa bền vững mà hệ thống đã xác nhận COMMIT.
